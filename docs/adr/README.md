# Architecture decision records

Neon Nine uses architecture decision records (ADRs) to preserve the context,
trade-offs, and consequences of decisions that materially affect the product.
Accepted ADRs remain immutable; a later change is recorded as a superseding
ADR rather than rewriting history.
